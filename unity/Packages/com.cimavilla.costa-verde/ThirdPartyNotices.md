# Procedencia de recursos

El frontal y los botones se renderizan desde la versión Costa Verde 2000 de este repositorio. Los símbolos SVG, monedas y foley se crearon para el minijuego. El entorno del chigre y el cristal del Cantábrico se generaron para esa versión. Las dos locuciones originales también se generaron para esta máquina y se distribuyen localmente; el paquete no utiliza servicios de generación durante la partida.

Las fuentes se convierten desde los WOFF2 locales a TTF, conservando sus datos y nombres:

- **DM Sans**: SIL Open Font License; `Fonts/dm-sans-OFL.txt`.
- **Cormorant Garamond**: SIL Open Font License; `Fonts/cormorant-garamond-OFL.txt`.
- **Barlow Condensed**: SIL Open Font License; `Fonts/barlow-condensed-OFL.txt`.

Input System, UGUI y Newtonsoft JSON se resuelven como paquetes de Unity y conservan sus respectivos avisos/licencias. Este aviso identifica la procedencia de los recursos; no modifica la licencia del repositorio.
